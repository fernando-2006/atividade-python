# Atividades Python

Quatro programas simples que rodam no terminal.
Pra executar qualquer programa, é só ir em sua respectiva pasta e rodar "python nome_do_arquivo.py".

---

## Os projetos

1. Calculadora

Uma calculadora básica com soma, subtração, multiplicação e divisão. Você digita dois números e escolhe a operação.

---

2. Biblioteca de Usuários

Cadastra uma lista de nomes; então, pode pesquisar por nomes específicos.

- Cadastre os 5 usuários
- Se você deixar o campo vazio, ele simplesmente pula aquele usuário
- Depois mostra os nomes registrados e quantos foram
- Então pode pesquisar cada um

---

3. Média de Aluno

Pega 3 notas de um aluno e calcula a média. Então decide se ele passou, ficou de recuperação ou reprovou.

- Puxa 3 notas (pode mudar no trecho de CONFIG)
- Checa a nota de aprovação padrão
- Entra em recuperação se a nota for baixa demais

---

4. Verificação de Número (`verificao_numero.py`)

Digita um número inteiro e o programa dirá se é positivo, negativo ou zero, e se é par ou ímpar.

- Checa positivo, negativo ou zero
- Checa par ou ímpar
- Curiosidade: zero não é classificado como par ou ímpar, por isso tem uma mensagem própria
